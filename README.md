# 화일철 라벨 인쇄 도우미

브라우저에서 바로 입력하고 A4 한 장으로 인쇄하는 정적 웹페이지입니다.

## 파일 구성

- `index.html`: 화면 구조와 A4 인쇄 미리보기 마크업
- `styles.css`: 화면 UI, A4 실측(mm) 배치, 인쇄 전용 스타일
- `app.js`: 입력값 반영, `localStorage` 저장, 토글 옵션, `window.print()` 연결

## 실행 방법

### 가장 간단한 방법

`index.html` 파일을 브라우저에서 바로 열면 됩니다.

### 로컬 서버로 실행하고 싶다면

아래 명령 중 하나를 사용할 수 있습니다.

```bash
python -m http.server 5500
```

그 다음 브라우저에서 `http://localhost:5500` 을 열면 됩니다.

## 사용 흐름

1. 왼쪽 입력 패널에서 라벨 내용을 입력합니다.
2. 오른쪽 A4 미리보기에서 실제 배치를 확인합니다.
3. 필요하면 재단선, 재단 순서 안내를 켜거나 끕니다.
4. `인쇄하기` 버튼을 눌러 브라우저 인쇄 창을 엽니다.
5. 인쇄 설정에서 배율을 `100%` 또는 `실제 크기`로 맞춥니다.

## 구현 메모

- 서버 없이 동작하는 순수 정적 페이지입니다.
- 광고 영역은 화면에만 보이고, 인쇄 시에는 숨겨집니다.
- 입력값은 `localStorage`에 저장되어 새로고침 후에도 유지됩니다.
- 현재 템플릿은 1종이며, 이후 템플릿 추가 시 `index.html`의 시트 마크업과 `styles.css`의 템플릿 블록을 추가하는 방식으로 확장할 수 있습니다.
